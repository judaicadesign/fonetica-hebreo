Fonética Hebrea Sefaradí v21

Pegá hebreo con o sin niqqud. Si ya tiene niqqud, se conserva exactamente. Si no tiene, lo vocaliza automáticamente con Nakdan y genera la fonética. Si Nakdan no está disponible, usa el motor local como respaldo.

Listo. Nakdan se activa automáticamente cuando hace falta.
Motor listo.
Reglas maestras activas

Principio: el hebreo vocalizado es siempre la fuente de verdad. El motor no corrige ni normaliza el hebreo desde la fonética.

ע → ' exclusivamente.
א → nunca genera apóstrofo.
צ / ץ → ts.
בּ / ב → b / v.
כּ / כ / ך → k / j / j.
ח → j.
שׁ / שׂ → sh / s.
ת / תּ → t.
Pataj / kamatz gadol → a.
Kamatz katán → o.
Segol / tzere → e.
Jirik → i.
Jolam → o.
Kubutz / shuruk → u.
Tzere nunca → ei.
La tilde depende del acento, no del nombre del niqqud.
י puede ser y, i o parte de un diptongo/hiato según su función.
הּ final → h.
וַיְ־ en las formas litúrgicas fijadas → vai- (Vaijal, Vaijulú, Vaivárej, Vaikadésh).
וַיִּ־ → vai + i (Vaishbót).
No se agregan prefijos que no estén en el hebreo.
No se fusionan palabras hebreas independientes.
Guion solo cuando evita ambigüedad; Ad-nai conserva su guion editorial.
Mayúscula después de punto; nombres propios y referencias divinas según criterio editorial.
