## Para abrir y usar

1. Entrá con tu cuenta a [GitHub — Judaica Design](https://github.com/judaicadesign/fonetica-hebreo/tree/desarrollo/auditoria-tehilim-150/masters/bircat-hamazon).
2. Tocá el archivo de Ashkenaz o Sefaradí en la tabla de arriba.
3. Podés **leerlo**, buscar palabras, copiar fragmentos o usar el botón **Raw** / **Download raw file** para bajar el TXT y abrirlo en Word o Bloc de notas.
4. Si encontrás un error, **no edites el único master por encima**: registramos la corrección en una versión nueva y la revisamos.

GitHub es un **archivo de originales con historial de versiones**: no translitera por sí solo. La conversión de hebreo a fonética pertenece al generador.
